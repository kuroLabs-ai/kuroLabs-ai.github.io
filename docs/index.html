01. Quickstart & Environment Setup

KuroCodeAgent (kurocode v0.2.0) is a local-first autonomous AI coding agent and desktop system engineer. It requires Python 3.10+ and operates with zero cloud telemetry. When paired with Ollama, it functions 100% offline.

Installation Commands (Windows / Linux / macOS) 
# 1. Clone the repository
git clone https://github.com/kurolabs-ai/KuroCodeAgent.git
cd KuroCodeAgent

# 2. Create and activate a Python virtual environment
python -m venv venv

# On Windows (PowerShell):
.\venv\Scripts\activate

# On Linux / macOS (bash/zsh):
source venv/bin/activate

# 3. Install in development mode
pip install -e .

# 4. Launch KuroCode interactive REPL
kuro
Dual Interface Support

CLI REPL & Desktop Assistant

KuroCode supports both an interactive terminal REPL (powered by Prompt-Toolkit and Rich) and a multi-modal desktop assistant with voice synthesis (edge-tts), voice input (SpeechRecognition), and visual screen capture (Pillow).

02. Configuration & Encrypted Vault

KuroCode supports multi-model task routing across Google Gemini, Groq (Llama-3), OpenRouter, and local offline Ollama endpoints. Credentials can be secured using the zero-footprint hardware vault or a standard .env file.

Method A: Hardware Vault

Zero Disk Footprint

Encrypts secrets using Windows DPAPI (or OS keyring on Linux/macOS) directly inside the running terminal: 

kuro > /vault set GEMINI_API_KEY AIzaSy... "Google Gemini API Key"
kuro > /vault set GROQ_API_KEY gsk_... "Groq Cloud Key"
kuro > /vault list
kuro > /vault migrate

Method B: Local .env File

Create a .env file in the project directory using template variables: 

KURO_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
GROQ_API_KEY=your_groq_api_key_here
OLLAMA_BASE_URL=http://localhost:11434/v1
KURO_SAFE_MODE=true

04. The Store Runtime Architecture

The Store engine (src/kurocode/store/manager.py) is the internal subsystem inside KuroCodeAgent responsible for discovering, downloading, validating, and hot-registering capabilities at runtime.

Core Store Responsibilities

  • Remote Sync: Fetches and parses catalog.json from kurolabs-ai/hub via urllib.
  • Pre-Execution AST Inspection: All Python files downloaded from URLs are scanned by sandbox_guard before execution.
  • Hot-Reloading: Registers new callables directly into the active ReAct tool registry without restarting the session.
  • URL Installation: Supports direct installation from arbitrary raw GitHub or web URLs via /store install <url>.

Store Execution Lifecycle

  1. User executes /store install <name> in REPL.
  2. StoreManager resolves item from in-memory catalog or raw Hub path.
  3. Payload is parsed (Tool, Plugin, Skill, or Integration).
  4. AST safety gate verifies signature and calls.
  5. Item is registered and marked installed: true in local SQLite/JSON ledger.

05. Capability Hub Registry & Schema Reference

The official community registry (kurolabs-ai/hub) maintains the decentralized capability catalog. Standalone source files live in tools/, plugins/, and skills/.

catalog.json Schema Specification

Field Type Required Description
id string Yes Unique ID prefixed by type (e.g. tool_hash_calculator, skill_tdd_refactoring)
name string Yes Human-readable identifier used for /store install <name>
item_type string Yes One of: "tool", "plugin", "skill", "integration"
description string Yes Brief description of capabilities and behavior
version string Yes Semantic version string (e.g. "1.0.0")
author string Yes GitHub username or team organization
tags string[] Yes Search keywords for /store search <query>
file_path string Optional Relative path from repo root (e.g. tools/my_tool.py)
payload object Yes Type-specific metadata (entrypoint, manifest_path, steps, connector_module, required_env)

06. Authoring & Contributing Capabilities

Follow the standardized 5-step contribution workflow from kurolabs-ai/hub to publish your capability:

Option A: Python Tool

tools/<name>.py

Self-contained Python module returning a dictionary: 

def my_tool(arg: str) -> dict:
    try:
        res = compute(arg)
        return {"success": True, "data": res}
    except Exception as e:
        return {"success": False, "error": str(e)}
Option B: Modular Plugin

plugins/<name>/

Package containing plugin.json manifest and main.py: 

{
  "name": "my_plugin",
  "version": "1.0.0",
  "description": "Custom plugin",
  "entrypoint": "main.py"
}
Option C: Procedural Skill

skills/<name>/SKILL.md

Markdown procedure with YAML frontmatter: 

---
name: my_routine
version: 1.0.0
description: Routine
author: YourUsername
tags: [workflow]
---
# Routine Steps...

5-Step Pull Request Workflow

  1. Fork & Clone: git clone https://github.com/<your-user>/hub.git
  2. Create Branch: git checkout -b feat/add-<capability-name>
  3. Author Capability: Add file in tools/, plugins/, or skills/.
  4. Update catalog.json: Append entry matching the schema above.
  5. Open PR: Submit PR to kurolabs-ai/hub:main. Once merged, it is immediately discoverable in KuroCode!

07. Troubleshooting & Frequently Asked Questions

Q: Can I use KuroCodeAgent without an internet connection?

Yes. Set KURO_PROVIDER=ollama and configure your local Ollama endpoint (e.g. http://localhost:11434/v1). All AST parsing, self-healing diagnostics, and code execution run 100% locally with zero external network calls.

Q: How does the AST Safety Sandbox protect my operating system?

Before executing any Python or shell code, KuroCode parses the Abstract Syntax Tree (ast.parse) to verify that prohibited calls (such as destructive system formatting, unpinned file wipes, or arbitrary token abuse) are intercepted before kernel execution. You can toggle safety prompts using /safe off when running inside an isolated VM.

Q: How do I install capabilities directly from a custom URL?

Execute /store install <raw_url>. KuroCode downloads the file, validates the Python code through the AST safety guard, generates an entrypoint function, and hot-registers it into the active session without requiring a restart.

Q: How do I report a vulnerability or issue?

Open an issue or Pull Request at the KuroCodeAgent Issues Tracker or submit security disclosures via GitHub Advisories.
