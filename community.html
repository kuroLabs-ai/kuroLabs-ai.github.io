Community & Participation

KuroLabs is built on open collaboration. We invite engineers, developers, and researchers to explore our repositories, report bugs, improve documentation, and contribute new modular capabilities.

01

/ Standard Contribution Flow

1
Fork & Clone:

Fork the target repository on GitHub and create a dedicated branch for your feature or fix.

2
Local Verification:

Run test suites with pytest -v. KuroCode requires automated test coverage for all new actions.

3
Conventional Commits:

Format commit messages following standard conventions (e.g. feat: ..., fix: ...).

4
Open Pull Request:

Submit your pull request describing the motivation, implementation, and verification steps.

Note on Community Channels: Official technical discussions and RFCs occur directly on our public GitHub repositories. KuroLabs does not maintain unverified secondary chat groups.
