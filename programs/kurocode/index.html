System Architecture

Engineering Architecture

KuroCodeAgent is organized into decoupled Python subsystems inside src/kurocode/.

01

AST Safety Sandbox

Located in core/sandbox.py. Analyzes Python Abstract Syntax Trees before execution, blocking dangerous invocations (e.g. disk wipers, unapproved filesystem traversal, arbitrary system command execution).

02

Self-Healing Diagnostics

Located in healing/. Automatically captures execution tracebacks, isolates missing dependencies or malformed arguments, invokes isolated pip resolution, and supports atomic Git checkpoint rollback.

03

Multi-Model Task Router

Located in core/model_router.py. Dynamically routes queries between Google Gemini, Groq (Llama-3), OpenRouter, and local offline Ollama endpoints with zero-downtime automated failover.

04

Controlled Self-Evolution

Located in evolution/. Assesses task bottlenecks, dynamically generates new Python tools via tools/generator.py, compiles them, and tracks changes in an immutable ledger.

05

Hardware Encrypted Vault

Located in core/vault.py. Uses native Windows DPAPI and AES-256 encryption to store model API keys with zero plain-text file leakage.

06

4-Layer Hybrid SQLite Memory

Located in core/memory_db.py. Retains project context, session history, learned developer preferences, and tool performance metrics across restarts.

07

Dual Interface & Vision

Supports interactive terminal REPL and desktop assistant mode with speech recognition, voice synthesis, and multi-modal desktop screenshot vision analysis.

08

Enterprise Integrations

Located in integrations/. Out-of-the-box connectors for GitLab, GitHub, Slack, Discord, Telegram, Email, and Google Drive for automated team notifications and CI/CD operations.

09

The Store Engine

Located in store/manager.py. Communicates with kurolabs-ai/hub, supports 1-click install from raw URLs, validates AST signatures, and hot-activates capabilities without restart.

Setup Walkthrough

Installation & Local Setup

KuroCodeAgent requires Python 3.10 or higher. Follow these verified installation instructions:

Terminal — Setup Workflow

# Step 1: Clone repository

git clone https://github.com/kurolabs-ai/KuroCodeAgent.git

cd KuroCodeAgent

# Step 2: Initialize virtual environment

# Windows:

python -m venv venv

.\venv\Scripts\activate

# Linux / macOS:

python3 -m venv venv

source venv/bin/activate

# Step 3: Install dependencies in editable mode

pip install -e .

# Step 4: Configure credentials into encrypted vault

kuro

kuro > /vault set GEMINI_API_KEY AIzaSy... "Google Gemini API Key"
