KURO 2.0 LEVEL 2 AUTONOMOUS REACT AGENT

The Autonomous, Local-First AI Terminal Assistant.

Unlike passive AI chat widgets, KURO has hands. It plans, executes shell commands, inspects live telemetry, validates outcomes with deterministic AST compilation, heals its own errors, and evolutes directly on your workstation.

VERIFIED CAPABILITIES

Engineered for Developer Autonomy

Features verified against the KuroCodeAgent 2.0 master specification and implementation.

01 / ORCHESTRATION

Autonomous ReAct Loop

Decomposes high-level instructions into multi-step actions. Never assumes success—validates each step with AST checks (py_compile) and exit code scrutiny.

Cascade: Gemini › Groq › OpenRouter › OpenAI › Ollama
02 / RESILIENCE

Self-Healing Engine

Failure classifier detects errors across 10 structured categories. Triggers automated pip install, path creation, or git-stash rollback checkpoints.

Safety Net: Automated Git Checkpoint & /undo
03 / SECURITY

Windows DPAPI Vault

Hardware-backed encryption for API keys tied to your Windows OS user profile (CryptProtectData) with AES-256 fallback on Linux/macOS.

AST Guard: Blocks malicious imports & shell wipes
04 / EXTENSIBILITY

Modular Puzzle Store

Synchronize, install, and hot-load tools, plugins, procedural skills, and external bridges from KuroHub without restarting the running agent session.

CLI Sync: /hub install <item>
05 / TELEMETRY & VISION

Desktop Vision & Telemetry

Inspects screen grabs to diagnose visual layout bugs, runs Playwright browser automation, and reads live CPU, RAM, and disk utilization statistics.

Commands: /system and /top
06 / INTEGRATIONS

External Bridges

Connect terminal notifications to Discord webhooks, Telegram bots, GitHub PRs/issues, GitLab pipelines, or Google Drive file storage.

Command: /integrations connect
EXECUTION FLOW

Deterministic ReAct Architecture

How KuroCodeAgent processes user instructions from terminal input to verified disk modification.

STEP 1
User Request

Terminal CLI input, slash command, or headless single-shot string.

STEP 2
Agent Orchestration

Context engine synthesizes prompt; ModelRouter selects active LLM provider.

STEP 3
Permission Gate

Safe Mode verifies AST security; blocks destructive calls unless approved.

STEP 4
Tool Execution

Invokes local tools or modular puzzle pieces loaded from Kuro Hub.

STEP 5
Verification & Heal

Validates AST & exit codes; triggers auto-pip or rollback on failure.
