# Core Module Breakdown

core.agent.KuroAgent

Coordinates the ReAct execution lifecycle: Goal Decomposition → Thought Synthesis → Action Dispatch → Observation Ingestion → Termination Check.

core.model_router.ModelRouter

Routes prompts based on task characteristics (e.g. reasoning vs. low-latency token streaming) and cascades across alternative API providers on HTTP 429 rate limit errors.

core.sandbox.SandboxGuard

Applies Python AST inspection prior to dynamic tool execution. Identifies prohibited AST nodes, unauthorized disk wiping commands (rm -rf, format), and unapproved network calls.

healing.SelfHealingEngine

Autonomous error recovery pipeline. Classifies exceptions into structured diagnostic categories and resolves issues (e.g. installing missing modules or rolling back corrupt diffs) before reporting failure.

# Deterministic Verification & Healing

Passive chat widgets assume an operation succeeded if the language model says so. KURO rejects this assumption:

  • 1. File Presence & Diff Audit: Every created or edited file is immediately validated on disk with stat checks and byte comparison.
  • 2. AST Syntax Compilation: Python source code changes are pre-compiled with py_compile to ensure no broken syntax is committed.
  • 3. Git Safety Rollbacks: If an automated change produces errors, KURO triggers /undo via internal stash checkpoints to restore pristine state.
